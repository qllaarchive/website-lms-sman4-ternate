1. Profil Proyek

Portal LMS SMA Negeri 4 Ternate — aplikasi web statis (HTML/CSS/JS) berbasis PWA yang mengelola daftar LMS per mata pelajaran untuk kelas X, XI, dan XII.

2. Teknologi yang Digunakan

KomponenTeknologiAlasan
FrontendHTML5, CSS3, Vanilla JSRingan, offline-first, mudah di-deploy
PWAService Worker + Web ManifestBisa dipasang di HP, mode offline
BackendNode.js + Express + PrismaREST API, autentikasi JWT
DatabasePostgreSQL 16Relational, ACID, gratis
Web ServerNginxCepat, reverse proxy, security headers
DeploymentUbuntu VPS + Docker ComposeReproducible, mudah maintain

4. Fitur Utama

  • Kartu LMS per mapel dengan progress bar
  • Pencarian mapel real-time
  • Login admin + CRUD LMS (tambah/ubah/hapus)
  • Pantau progres siswa + ekspor CSV
  • Pengumuman sekolah
  • Profil sekolah + info PPDB
  • Mode gelap/terang + tema otomatis
  • Offline-first (Service Worker cache)

5. Deployment di Ubuntu

  1. Install Docker + Docker Compose
  2. git pull dari GitHub
  3. docker compose up -d --build
  4. Setup Nginx reverse proxy + Certbot (HTTPS)
  5. Setup GitHub Actions CI/CD
